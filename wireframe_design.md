# プロフィール画面 基本設計書

## 1. 概要

- URL：`/profile`
- 目的：ユーザーの実績とプロフィール情報を表示するページ。

## 2. ワイヤーフレーム

```text
+----------------------------------------------------------------+
| Engineer Guild                       [設定] [ログアウト]       |
+----------------------------------------------------------------+
|                                                                |
|   +------------+  +------------------------------------+       |
|   |  アバター  |  |  ユーザー名                        |       |
|   |    画像    |  |  ランク：シルバー                  |       |
|   +------------+  +------------------------------------+       |
|                                                                |
|   === 実績一覧 ===                                             |
|                                                                |
|   +------------+  +------------+  +------------+               |
|   |   実績1    |  |   実績2    |  |   実績3    |               |
|   +------------+  +------------+  +------------+               |
|                                                                |
+----------------------------------------------------------------+
| © 2026 Engineer Guild                                          |
+----------------------------------------------------------------+
```

## 3. コンポーネント一覧

| コンポーネント  | 責務                   | 再利用可否            |
| --------------- | ---------------------- | --------------------- |
| Header          | ナビゲーション表示     | ✅ 全ページ共通       |
| ProfileCard     | プロフィール情報の表示 | ✖ このページ専用      |
| AchievementGrid | 実績の一覧表示         | ✖ このページ専用      |
| AchievementCard | 実績1件の表示          | ✅ 他ページでも利用可 |
| Footer          | フッター情報           | ✅ 全ページ共通       |

## 4. レイアウト設計

| エリア名             | 使用CSSレイアウト手法                               |
| -------------------- | --------------------------------------------------- |
| ヘッダー             | Flexbox（`justify-content: space-between`）         |
| プロフィールブロック | Flexbox（`align-items: center`、`gap: 20px`）       |
| 実績グリッド         | CSS Grid（`grid-template-columns: repeat(3, 1fr)`） |
